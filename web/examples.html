Scientific Calculator

Inline Instant answers on every website: every kind of maths and chemistry it finds, each example with the icons it should get. Hover an icon for its answer; a click opens it in the calculator.

Checking…A green line: the example has the icons it should; a red one: it has not.

How it runs: the extension installed does the work: turn on Inline Instant answers on every website in its options, and reload this page. opened from the test folder of the repository, or from its server, the page puts in the extension's own scripts from ../js, so it tests the code as it is now; a click shows at the bottom what it would open. With ?extension after its address it leaves them out, for the extension installed to do its work.

Equations and inequalities

Of x should work

  1. Linear: Solve 2x + 3 = 7 first.
  2. Quadratic: x² − 5x + 6 = 0
  3. A cubic: x^3 = 2x + 1
  4. Quintic: x^5 − 3x^3 + x − 1 = 0
  5. Biquadratic: x⁴ − 10x² + 9 = 0
  6. Factored: (x − 1)(x − 2)(x − 3) = 0
  7. With a tag power: x2 − 2x + 1 = 0
  8. Exponential: 2^x = 1024
  9. Logarithmic: log(x) = 3
  10. Mixed: ln(x) + x = 5
  11. Trig: sin(x) = cos(x)
  12. Radical: √(x + 3) = x − 3
  13. Absolute value: abs(x − 2) = 5
  14. Rational: 1/x + 1/(x + 1) = 1
  15. Both sides: 3x + 7 = 2x − 5
  16. Decimals: 0.5x − 1.25 = 3.75
  17. No real root: x^2 + 1 = 0
  18. Cubic inequality: x^3 − x > 0
  19. Linear inequality: 2x + 1 ≥ 3x − 4
  20. Square inequality: x² ≤ 9, and x^2 − 4 > 0
  21. Double inequality: −2 < 3x + 1 < 7

Together: two or three equations should work

  1. Two lines: Solve 2x + y = 5, x − y = 1 together.
  2. Three planes: x + y + z = 6, 2x − y + z = 3, x + 2y − z = 2.
  3. A circle and a line: x² + y² = 25 and x + y = 7.
  4. One line twice: x + y = 1, 2x + 2y = 2

Functions to draw should work

  1. A parabola: y = x² − 4x + 3
  2. A named function: f(x) = sin(x)/x
  3. Growth: g(x) = 2^x
  4. A cubic: h(x) = x³ − 3x
  5. With asymptotes: y = tan(x)
  6. A line: y = 2x + 1
  7. Not one: y = 5, y = x, y = mx + b
